# URL Checker

## What it does
This app checks a URL:

- if it is valid  
- if it exists (mocked)  
- if it is a file or folder  

---

## How to run
Open `index.html` in your browser.

---

## How it works
- Checks URL format in JavaScript  
- Uses a fake server (setTimeout)  
- Limits requests while typing (throttle)
